# Калькулятор лизинга BCC Leasing

Клиент пишет параметры сделки своими словами, бот распознаёт стоимость, аванс и срок, считает аннуитет по формуле из блока E и показывает график, переплату, пояснение, дисклеймер и кнопку заявки.

Адрес: https://bakhtiyardt.github.io/bcc-summit/leasing/

## Как устроено

- `calc.js` — формула и разбор текста правилами (работает без ИИ, мгновенно).
- `app.js` — чат, карточка параметров с ползунками, результат, график.
- `pdf.js` — выгрузка расчёта в PDF (jsPDF + AutoTable из `vendor/`, шрифт Inter с кириллицей и ₸ из `fonts/`, OFL). Загружается только при нажатии «Скачать PDF».
- `config.js` — параметры расчёта: ставка 18% годовых, срок 12–60 мес., аванс от 10%, адрес ИИ.
- `edge-function/index.ts` — Supabase Edge Function `lease-ai` на Claude Haiku 4.5: извлекает параметры из сложных фраз и пишет пояснение. **Цифры модель не считает** — только код по формуле.

Гибрид: если правила распознали всё, ИИ не вызывается; иначе текст уходит в ИИ. Если ИИ недоступен, работает режим правил.

## Подключение ИИ (один раз)

1. Supabase → проект bcc-summit → **Edge Functions** → **Deploy a new function** → **Via Editor**.
2. Имя функции: `lease-ai`. Вставить содержимое `edge-function/index.ts`, нажать **Deploy**.
3. У функции открыть **Details** и выключить **Verify JWT with legacy secret** (страница передаёт publishable-ключ, а не JWT). Сохранить.
4. **Edge Functions → Secrets** → добавить:
   - `ANTHROPIC_API_KEY` — ключ из console.anthropic.com;
   - `RESEND_API_KEY` — ключ из resend.com (для отправки заявок);
   - `LEAD_EMAIL` — адрес, куда приходят заявки с PDF.

Заявка: клиент указывает имя и телефон, страница формирует PDF с контактами и графиком, функция отправляет его письмом на `LEAD_EMAIL` через Resend. Адрес получателя хранится только в секрете.

После саммита ключ лучше отозвать: функция открыта для вызова со страницы.

## Контрольные сценарии (ставка 18% годовых)

| Запрос | Платёж, ₸ | Переплата, ₸ |
|---|---|---|
| Оборудование за 10 млн тенге, аванс 20%, на 24 месяца | 399 393 | 1 585 428 |
| Спецтехника 45 000 000, первоначальный взнос 9 млн, срок 3 года | 1 301 486 | 10 853 505 |
| Автомобиль 18,5 млн на 5 лет, аванс 15% | 399 312 | 8 233 699 |
| Грузовик 32 млн, аванс 30%, 12 мес | 2 053 632 | 2 243 582 |

Эталон считается независимо (`tests/reference.py`, Decimal). Сверка: `node leasing/tests/test.js` — расчёт совпадает с эталоном до 0,01 ₸ по каждому месяцу, плюс проверка разбора фраз и опечаток.
