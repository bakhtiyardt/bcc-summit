# Опросы BCC Life

Веб-приложение для опросов: автор создаёт опрос (варианты ответа подбираются автоматически и редактируются), публикует его и получает ссылку и большой QR-код с логотипом BCC Life. Участники отвечают с телефона без регистрации. Результаты (число анкет, количество и процент по каждому варианту) видит только автор.

Хостинг: GitHub Pages (статические файлы). База: Supabase.

## Установка

1. Supabase → SQL Editor → вставить `supabase.sql` → Run.
2. В `config.js` вписать Project URL и публичный anon/publishable-ключ.
3. GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Безопасность

Таблицы закрыты RLS, страница работает только через функции в базе:
- участник читает опубликованный опрос и отправляет одну анкету (ответы проверяются на сервере);
- редактирование, закрытие, удаление и результаты требуют секретный ключ автора (в базе хранится только его SHA-256);
- персональные данные не собираются.

Ключ автора хранится в браузере. Чтобы открыть свои опросы на другом устройстве, используйте «Ключ автора» внизу списка опросов.
